# 04 Security and Compliance Checklist

- Security policy document
- Access control policy and RBAC model
- Password and authentication policy
- Data retention and deletion policy
- Incident response playbook
- Vulnerability management process
- Security headers and encryption standards
- Third-party subprocessor list
- Compliance gap assessment (DPDP, GDPR readiness)
- External security audit report (if available)

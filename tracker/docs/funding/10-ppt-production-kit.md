# AlcoveHire PPT Production Kit (Build in 60-90 Minutes)

Objective:
- Build a professional 12-slide investor deck in PowerPoint with consistent visual language.
- Use this as a direct build checklist.

## 1) Deck Setup (Before Slide Design)

Slide size:
- Widescreen 16:9

Theme:
- Background: #F4F7FB
- Primary: #0F4C81
- Accent: #1E7A73
- Text dark: #1D2736
- Muted text: #5E6B7E

Fonts:
- Heading: Manrope Semibold
- Body: Source Sans 3 Regular
- Number highlights: Manrope Bold

Spacing system:
- Outer margin: 0.6 inch
- Content columns: 12-column grid
- Card padding: 16 to 20 px equivalent

Icon style:
- Outline or two-tone business icons only
- Keep icon color to primary or muted gray

## 2) Master Slide Components

Create these masters in Slide Master:
- Master A: Title + subtitle + full-width visual
- Master B: Title + two-column content
- Master C: Title + 3 KPI cards
- Master D: Title + chart + insight box
- Master E: Timeline/Gantt layout

Common footer:
- Left: AlcoveHire
- Right: Confidential | Month Year
- Page number on all slides except cover

## 4) Animation and Transition Rules

- Transition: Fade only, 0.3s
- Use appear animation by groups, not one bullet at a time
- Avoid zoom/spin effects
- Charts animate by category once

## 5) PowerPoint Build Sequence

1. Apply theme colors and fonts in Slide Master.
2. Build Slide 1 and Slide 2 as style anchors.
3. Insert all chart placeholders first.
4. Import CSV data into charts.
5. Add speaker notes from investor deck script.
6. Final consistency pass: spacing, alignment, font sizes.

## 6) Quality Checklist Before Sharing

- Every slide has one clear headline message.
- Numbers consistent across slides and memo.
- Same currency format everywhere.
- No dense paragraphs.
- Contrast ratio readable in projector mode.
- Export final as PPTX and backup PDF.
